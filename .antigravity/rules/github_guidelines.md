# GitHub Guidelines

## Gemini Added Memories
- For any GitHub-related content (issues, pull requests, commits, etc.), always use the English language.
- When creating GitHub issues, never use checkboxes; use exclusively bulleted lists.
- For git commits: DO NOT ask the user to run the commit themselves. Instead, propose a commit message to the user, wait for their confirmation, and then autonomously execute the `git commit` command on their behalf. This explicitly overrides any global rule that says "don't commit the modified code".
